# Документація Spam Scanner

Spam Scanner — це спам-фільтр для Node.js і командного рядка з вихідним кодом на GitHub. Він читає необроблений лист електронної пошти і визначає, чи це спам, фішинг, шахрайство або лист зі шкідливим ПЗ, будь-якою мовою. Він працює як бібліотека, інструмент командного рядка, milter для Postfix або Sendmail, контент-фільтр Postfix, сумісний зі SpamAssassin сервер spamd, HTTP API або TCP-сервер.

Його створює [Forward Email](https://forwardemail.net) для власних поштових серверів.


## Як оцінюється лист

Кожна перевірка додає або знімає бали. Сума визначає результат:

| Бал           | Дія      | Що робить поштовий сервер         |
| ------------- | -------- | --------------------------------- |
| Менше 5       | `accept` | Доставляє лист                    |
| Від 5 до 14,9 | `tag`    | Доставляє його з позначкою «спам» |
| 15 і більше   | `reject` | Відхиляє його під час сеансу SMTP |

Обидва пороги можна змінити. Кожен результат перелічує тести, що спрацювали, з їхніми балами й причиною, тож рішення завжди можна пояснити.

Перевірки:

* **Навчений класифікатор** читає слова листа будь-якою писемністю, форму його посилань, відправника та вкладення. Він постачається навченим на відкритих наборах даних і вчиться на вашій власній пошті. [Як працює класифікатор](how-it-works.md#the-classifier)
* **Перевірки на фішинг** виявляють схожі домени (`paypa1.com`, `pаypal.com` з кириличною «а»), посилання, текст яких показує одну адресу, а ціль є іншою, та імена відправника, що видають себе за бренд. [Фішинг](how-it-works.md#phishing)
* **Перевірки вкладень** знаходять виконувані файли, виконувані файли, перейменовані на документи, подвійні розширення, трюки з написанням імені файлу справа наліво, виконувані файли в ZIP-архівах, макроси Office та активний вміст PDF. ClamAV може перевіряти вкладення на віруси. [Вкладення](how-it-works.md#attachments)
* **Автентифікація**: SPF, DKIM, DMARC і ARC, коли IP-адреса клієнта відома. [Автентифікація](how-it-works.md#authentication)
* **Чорні списки DNS** для IP-адреси клієнта та доменів у посиланнях, а також фільтрувальні резолвери Cloudflare для відомих сайтів зі шкідливим ПЗ і сайтів для дорослих. [Чорні списки](how-it-works.md#blocklists)
* **Правила** для шаблонів, яких жодному класифікатору не треба вчитися: тестовий рядок GTUBE, теми листів із сексторшеном, шахрайські рахунки PayPal, підробка власного домену й інструкції, приховані для ШІ-фільтрів. [Правила](scoring.md#rules)
* **Мовна модель**, за бажанням, дає другу думку щодо спірних випадків: локальна модель через Ollama або будь-який сервер, сумісний з OpenAI, модель рішень на кшталт Clef від Cloudflare, чи Claude, ChatGPT, Gemini та інші. За замовчуванням вона за один крок повертає ймовірність кожного вердикту замість того, щоб писати відповідь. [Мовні моделі](llm.md)
