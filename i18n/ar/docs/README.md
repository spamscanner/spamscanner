# توثيق Spam Scanner

Spam Scanner مرشِّح بريد مزعج لـ Node.js وسطر الأوامر، وشيفرته المصدرية على GitHub. يقرأ رسالة بريد إلكتروني خامًا ويقرر هل هي بريد مزعج، أو تصيّد احتيالي، أو احتيال، أو تحمل برمجيات خبيثة، بأي لغة. يعمل مكتبةً، أو أداة سطر أوامر، أو milter لـ Postfix أو Sendmail، أو مرشِّح محتوى لـ Postfix، أو خادم spamd متوافق مع SpamAssassin، أو واجهة HTTP API، أو خادم TCP.

بنته [Forward Email](https://forwardemail.net) لخوادم بريدها.


## كيف يُحكم على الرسالة

كل فحص يضيف نقاطًا أو يحذفها. المجموع يحدد النتيجة:

| الدرجة        | الإجراء  | ما يفعله خادم البريد       |
| ------------- | -------- | -------------------------- |
| أقل من 5      | `accept` | يسلّم الرسالة              |
| من 5 إلى 14.9 | `tag`    | يسلّمها موسومة بأنها مزعجة |
| 15 فأكثر      | `reject` | يرفضها أثناء جلسة SMTP     |

يمكن تغيير العتبتين كلتيهما. كل نتيجة تسرد الاختبارات التي انطبقت، مع نقاطها وسببها، فيمكن دائمًا شرح القرار.

الفحوص:

* **مصنِّف مدرَّب** يقرأ كلمات الرسالة بأي نظام كتابة، وشكل روابطها، ومرسلها، ومرفقاتها. يأتي مدرَّبًا على مجموعات بيانات عامة ويتعلم من بريدك. [كيف يعمل المصنِّف](how-it-works.md#the-classifier)
* **فحوص التصيّد الاحتيالي** تلتقط النطاقات المشابهة (`paypa1.com`، و`pаypal.com` بحرف а سيريلي)، والروابط التي يُظهر نصها عنوانًا ويؤدي هدفها إلى عنوان آخر، وأسماء العرض التي تدّعي علامة تجارية. [التصيّد الاحتيالي](how-it-works.md#phishing)
* **فحوص المرفقات** تكتشف الملفات التنفيذية، والملفات التنفيذية المعاد تسميتها كمستندات، والامتدادات المزدوجة، وحيل أسماء الملفات من اليمين إلى اليسار، والملفات التنفيذية داخل ملفات ZIP، ووحدات الماكرو في Office، ومحتوى PDF النشط. يستطيع ClamAV فحص المرفقات بحثًا عن الفيروسات. [المرفقات](how-it-works.md#attachments)
* **المصادقة**: SPF وDKIM وDMARC وARC، عندما يكون عنوان IP للعميل معروفًا. [المصادقة](how-it-works.md#authentication)
* **قوائم حظر DNS** لعنوان IP للعميل وللنطاقات في الروابط، ومحلِّلات Cloudflare الترشيحية للبرمجيات الخبيثة ومواقع البالغين المعروفة. [قوائم الحظر](how-it-works.md#blocklists)
* **القواعد** للأنماط التي لا يحتاج أي مصنِّف إلى تعلّمها: سلسلة اختبار GTUBE، وعناوين الابتزاز الجنسي، واحتيالات فواتير PayPal، والانتحال الذاتي، والتعليمات المخفية الموجّهة إلى مرشِّحات الذكاء الاصطناعي. [القواعد](scoring.md#rules)
* **نموذج لغوي**، اختياري، يقدّم رأيًا ثانيًا في الحالات المتقاربة: نموذج محلي عبر Ollama أو أي خادم متوافق مع OpenAI، أو نموذج قرار مثل Clef من Cloudflare، أو Claude وChatGPT وGemini وغيرها. افتراضيًا يعيد احتمالًا لكل حكم في خطوة واحدة بدل أن يكتب إجابة. [النماذج اللغوية](llm.md)
