# התיעוד של Spam Scanner

Spam Scanner הוא מסנן ספאם עבור Node.js ושורת הפקודה, וקוד המקור שלו נמצא ב-GitHub. הוא קורא הודעת דואר אלקטרוני גולמית ומחליט אם היא ספאם, פישינג, הונאה או נושאת נוזקה, בכל שפה. הוא רץ כספרייה, ככלי שורת פקודה, כ-milter ל-Postfix או ל-Sendmail, כמסנן תוכן ל-Postfix, כשרת spamd תואם SpamAssassin, כ-HTTP API או כשרת TCP.

הוא נבנה על ידי [Forward Email](https://forwardemail.net) עבור שרתי הדואר שלה.


## איך הודעה נשפטת

כל בדיקה מוסיפה או מורידה נקודות. הסכום הכולל קובע את התוצאה:

| ניקוד     | פעולה    | מה שרת דואר עושה            |
| --------- | -------- | --------------------------- |
| מתחת ל-5  | `accept` | מוסר את ההודעה              |
| 5 עד 14.9 | `tag`    | מוסר אותה עם סימון כספאם    |
| 15 ומעלה  | `reject` | דוחה אותה במהלך שיחת ה-SMTP |

אפשר לשנות את שני הספים. כל תוצאה מפרטת את הבדיקות שהופעלו, עם הנקודות שלהן וסיבה, כך שתמיד אפשר להסביר החלטה.

הבדיקות:

* **מסווג מאומן** קורא את המילים של ההודעה בכל כתב, את צורת הקישורים שלה, את השולח שלה ואת הקבצים המצורפים שלה. הוא מגיע מאומן על מאגרי נתונים ציבוריים ולומד מהדואר שלכם. [איך המסווג עובד](how-it-works.md#the-classifier)
* **בדיקות פישינג** תופסות דומיינים מתחזים (`paypa1.com`, `pаypal.com` עם а קירילית), קישורים שהטקסט שלהם מציג כתובת אחת והיעד שלהם הוא אחר, ושמות תצוגה שמתיימרים להיות מותג. [פישינג](how-it-works.md#phishing)
* **בדיקות קבצים מצורפים** מוצאות קבצי הרצה, קבצי הרצה ששמם שונה כדי שייראו כמסמכים, סיומות כפולות, תכסיסי שמות קבצים מימין לשמאל, קבצי הרצה בתוך קובצי ZIP, פקודות מאקרו של Office ותוכן PDF פעיל. ClamAV יכול לסרוק קבצים מצורפים לאיתור וירוסים. [קבצים מצורפים](how-it-works.md#attachments)
* **אימות**: SPF,‏ DKIM,‏ DMARC ו-ARC, כשכתובת ה-IP של הלקוח ידועה. [אימות](how-it-works.md#authentication)
* **רשימות שחורות ב-DNS** לכתובת ה-IP של הלקוח ולדומיינים שבקישורים, ושרתי ה-DNS המסננים של Cloudflare לאתרי נוזקות ואתרי מבוגרים ידועים. [רשימות שחורות](how-it-works.md#blocklists)
* **כללים** לדפוסים שאף מסווג לא צריך ללמוד: מחרוזת הבדיקה GTUBE, נושאי סחטנות מינית, הונאות חשבוניות של PayPal, זיוף עצמי והוראות שמוסתרות עבור מסנני AI. [כללים](scoring.md#rules)
* **מודל שפה**, אופציונלי, נותן חוות דעת שנייה על מקרים גבוליים: מודל מקומי דרך Ollama או כל שרת תואם OpenAI, מודל החלטה כמו Clef של Cloudflare, או Claude,‏ ChatGPT,‏ Gemini ואחרים. כברירת מחדל הוא מחזיר הסתברות לכל פסק דין בצעד אחד, במקום לכתוב תשובה. [מודלי שפה](llm.md)
