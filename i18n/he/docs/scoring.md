# בדיקות וניקוד

הודעה היא ספאם ב-5 נקודות ונדחית ב-15. כל בדיקה שמופיעה כאן מוסיפה או מורידה נקודות; התוצאה מפרטת את הבדיקות שהופעלו.

את הספים משנים עם `threshold` ו-`rejectThreshold`. את הנקודות משנים עם `scores`, לפי מפתח הגדרה (`scores: {deceptiveLink: 4}`) או לפי שם הבדיקה, שקובע את הנקודות של אותה בדיקה (`scores: {FROM_NAME_BRAND: 4}`).


## מסווג

| בדיקה                     | נקודות          | משמעות                                                                                                                                                                                                                                                                                                       |
| ------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `BAYES_00` עד `BAYES_999` | ‎-2.5 עד ‎+6.25 | הסתברות הספאם של המסווג, בסולם לוג-סיכויים: 2.4 נקודות ב-90%, 5 ב-99% ו-6.25 ב-99.9%, כך שהמסווג מסמן ספאם לבדו רק כשהוא בטוח לפחות ב-99%. השם מציין את הטווח: `BAYES_999` הוא 99.9% ומעלה, `BAYES_99` מ-99% עד 99.9%, `BAYES_50` מ-40% עד 60%. מפתחות ההגדרה `bayesHam` ו-`bayesSpam` קובעים את שני הקצוות. |
