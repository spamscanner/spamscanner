# Тесты и баллы

Письмо считается спамом при 5 баллах и отклоняется при 15. Каждый тест ниже добавляет или снимает баллы; в результате перечислены сработавшие.

Пороги меняются через `threshold` и `rejectThreshold`. Баллы меняются через `scores` — либо по ключу настройки (`scores: {deceptiveLink: 4}`), либо по имени теста, что фиксирует баллы этого теста (`scores: {FROM_NAME_BRAND: 4}`).


## Классификатор

| Тест                      | Баллы            | Значение                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BAYES_00` до `BAYES_999` | от −2,5 до +6,25 | Вероятность спама по оценке классификатора в логарифмической шкале шансов: 2,4 балла при 90 %, 5 при 99 % и 6,25 при 99,9 %, поэтому классификатор сам помечает спам, только если уверен хотя бы на 99 %. Имя указывает диапазон: `BAYES_999` — 99,9 % и выше, `BAYES_99` — от 99 % до 99,9 %, `BAYES_50` — от 40 % до 60 %. Ключи настроек `bayesHam` и `bayesSpam` задают два крайних значения. |

## Правила

| Тест                      | Баллы | Значение                                                                                    |
| ------------------------- | ----: | ------------------------------------------------------------------------------------------- |
| `GTUBE`                   |  1000 | Тестовая строка GTUBE                                                                       |
| `SEXTORTION_SUBJECT`      |     6 | Тема, которую используют мошенники с сексуальным вымогательством и захватом учётных записей |
| `PAYPAL_INVOICE`          |     6 | Счёт или запрос денег через PayPal — канал, которым злоупотребляют мошенники                |
| `MICROSOFT_SPAM_VERDICT`  |     5 | Microsoft пометил письмо как спам перед пересылкой (доверяется только с серверов Microsoft) |
| `MICROSOFT_HIGH_SCL`      |     3 | Microsoft присвоил ему высокий уровень уверенности в спаме (аналогично)                     |
| `PROMPT_INJECTION`        |     3 | Текст, обращённый к ИИ-фильтру                                                              |
| `SELF_SPOOF`              |     3 | Выдаёт себя за письмо из собственного домена получателя и не проходит аутентификацию        |
| `FROM_NAME_OTHER_ADDRESS` |   2,5 | Отображаемое имя содержит другой адрес электронной почты                                    |
| `FROM_NAME_BRAND`         |     2 | Отображаемое имя выдаёт себя за бренд, которому адрес не принадлежит                        |
| `DATE_IN_FUTURE`          |     1 | Дата больше чем на сутки впереди                                                            |
| `MISSING_DATE`            |   0,5 | Нет заголовка Date                                                                          |
| `MISSING_MESSAGE_ID`      |   0,5 | Нет заголовка Message-ID                                                                    |

Правила, которые стоят не меньше порога спама, также появляются в `results.arbitrary`, как в прежних версиях.
