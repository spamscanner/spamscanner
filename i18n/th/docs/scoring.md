# การทดสอบและคะแนน

ข้อความถือเป็นสแปมที่ 5 คะแนน และถูกปฏิเสธที่ 15 คะแนน การทดสอบแต่ละรายการด้านล่างจะเพิ่มหรือลดคะแนน ผลลัพธ์แสดงรายการที่ทำงาน

เปลี่ยนเกณฑ์ด้วย `threshold` และ `rejectThreshold` เปลี่ยนคะแนนด้วย `scores` โดยระบุด้วยคีย์การตั้งค่า (`scores: {deceptiveLink: 4}`) หรือด้วยชื่อการทดสอบ ซึ่งจะกำหนดคะแนนของการทดสอบนั้นตายตัว (`scores: {FROM_NAME_BRAND: 4}`)


## ตัวจำแนก

| การทดสอบ                   | คะแนน          | ความหมาย                                                                                                                                                                                                                                                                                                                                    |
| -------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `BAYES_00` ถึง `BAYES_999` | -2.5 ถึง +6.25 | ความน่าจะเป็นของสแปมจากตัวจำแนก บนสเกล log-odds: 2.4 คะแนนที่ 90% 5 คะแนนที่ 99% และ 6.25 คะแนนที่ 99.9% ตัวจำแนกจึงตีว่าเป็นสแปมด้วยตัวเองก็ต่อเมื่อมั่นใจอย่างน้อย 99% ชื่อบอกช่วงค่า: `BAYES_999` คือ 99.9% ขึ้นไป `BAYES_99` คือ 99% ถึง 99.9% `BAYES_50` คือ 40% ถึง 60% คีย์การตั้งค่า `bayesHam` และ `bayesSpam` กำหนดค่าทั้งสองปลาย |

| `MIXED_SCRIPT_DOMAIN`       |     3 | `mixedScriptDomain` | label ของโดเมนใช้ตัวอักษรหลายระบบปนกัน                                 |
| `BRAND_IN_DOMAIN`           |   1.5 | `brandInDomain`     | ชื่อแบรนด์อยู่ในโดเมนของผู้อื่น                                        |
| `TYPO_DOMAIN`               |     1 | `typoDomain`        | ต่างจากโดเมนของแบรนด์หนึ่งตัวอักษร                                     |

| `MALICIOUS_DOMAIN`          |     6 | `maliciousDomain`   | resolver กันมัลแวร์ของ Cloudflare บล็อกโดเมนที่ลิงก์ไป                 |
| `ADULT_DOMAIN`              |     2 | `adultDomain`       | resolver สำหรับครอบครัวของ Cloudflare บล็อกโดเมนที่ลิงก์ไป             |
| `URIBL_<LIST>`              |     5 | `uriblListed`       | โดเมนที่ลิงก์ไปอยู่ใน domain blocklist เช่น `URIBL_DBL`                |

| `MICROSOFT_HIGH_SCL`      |     3 | Microsoft ให้ระดับความมั่นใจว่าเป็นสแปมสูง (เงื่อนไขเดียวกัน)                                         |

| `FROM_NAME_OTHER_ADDRESS` |   2.5 | ชื่อที่แสดงมีที่อยู่อีเมลอื่นอยู่ข้างใน                                                               |
| `FROM_NAME_BRAND`         |     2 | ชื่อที่แสดงอ้างว่าเป็นแบรนด์ที่ที่อยู่อีเมลไม่ได้เป็นของแบรนด์นั้น                                    |
| `DATE_IN_FUTURE`          |     1 | ลงวันที่ล่วงหน้าเกินหนึ่งวัน                                                                          |
| `MISSING_DATE`            |   0.5 | ไม่มีส่วนหัว Date                                                                                     |
| `MISSING_MESSAGE_ID`      |   0.5 | ไม่มีส่วนหัว Message-ID                                                                               |

กฎที่มีคะแนนอย่างน้อยเท่าเกณฑ์สแปมจะปรากฏใน `results.arbitrary` ด้วย เหมือนในเวอร์ชันก่อน ๆ

## ชื่อเสียงและ blocklist
