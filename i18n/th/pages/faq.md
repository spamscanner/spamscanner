# คำถามที่พบบ่อย


## Spam Scanner คืออะไร

ตัวกรองสแปมสำหรับ Node.js บรรทัดคำสั่ง และเซิร์ฟเวอร์อีเมล โปรแกรมอ่านข้อความอีเมลดิบแล้วตัดสินว่าเป็นสแปม ฟิชชิง การหลอกลวง หรือมีมัลแวร์หรือไม่ พร้อมคะแนนและรายการการทดสอบที่ใช้ตัดสิน ทำงานได้ทั้งในรูปไลบรารี milter สำหรับ Postfix และ Sendmail เซิร์ฟเวอร์ spamd ที่เข้ากันได้กับ SpamAssassin ตัวกรองเนื้อหาของ Postfix, HTTP API หรือเซิร์ฟเวอร์ TCP


## ใช้ฟรีหรือไม่

[สัญญาอนุญาต](https://github.com/spamscanner/spamscanner/blob/master/LICENSE) ของโครงการคือ Business Source License 1.1 ซึ่งอนุญาตให้ใช้งานได้ทุกรูปแบบ ยกเว้นการให้บริการตรวจจับสแปมแก่ผู้อื่น และระบุวันที่สัญญาอนุญาตจะเปลี่ยนเป็น Apache License 2.0


## แม่นยำแค่ไหน

กับข้อความภาษาอังกฤษที่กันไว้จากข้อมูลฝึก ตัวจำแนกที่มาพร้อมแพ็กเกจอย่างเดียวไม่ตี ham ใดเลยว่าเป็นสแปม และจับสแปมได้ 97% ตัวเลขทั้งหมดแยกตามภาษาอยู่ใน[คู่มือการฝึกโมเดล](../../docs/training.md#the-bundled-model) ลิงก์ ไฟล์แนบ การยืนยันตัวตน blocklist และโมเดลภาษาช่วยเพิ่มความแม่นยำอีก อีเมลของคุณเองคือการทดสอบที่แท้จริง: `spamscanner eval` วัดผลโมเดลใดก็ได้กับอีเมลใดก็ได้ที่ติดป้ายกำกับแล้ว


## รองรับภาษาใดบ้าง

ทุกภาษา โปรแกรมตัดคำตามกฎของ Unicode รวมถึงภาษาจีน ญี่ปุ่น และไทย ซึ่งไม่เว้นวรรค ในภาษาที่โมเดลที่มาพร้อมแพ็กเกจเคยเห็นอีเมลน้อย โมเดลจะคงสถานะไม่แน่ใจแทนการตีว่าเป็นสแปม แล้วให้โมเดลภาษาหรือการฝึกของคุณเองเป็นผู้ตัดสิน [ภาษา](../../docs/languages.md)


## ส่งอีเมลของฉันไปที่ใดหรือไม่

ไม่ โดยค่าเริ่มต้น โปรแกรมค้นหาชื่อโฮสต์ของลิงก์ใน DNS resolver แบบกรองของ Cloudflare และไม่มีอะไรอื่นถูกส่งออกจากเครื่อง การยืนยันตัวตน blocklist โมเดลภาษา และบริการด้านชื่อเสียงปิดไว้จนกว่าจะตั้งค่า และข้อมูลส่วนบุคคลจะถูกลบออกก่อนส่งอีเมลไปยังโมเดลภาษาแบบโฮสต์ [ความปลอดภัยและความเป็นส่วนตัว](../../docs/security.md)


## ต้องใช้โมเดลภาษาหรือไม่

ไม่ต้อง โมเดลภาษาเป็นความเห็นที่สองสำหรับกรณีที่ตัดสินยาก หากไม่มี ข้อความเหล่านั้นจะถูกตัดสินด้วยคะแนนอย่างเดียว


## ควรใช้โมเดลภาษาตัวใด

`qwen3.5:4b` ผ่าน Ollama บน CPU หรือ `qwen3.5:9b` เมื่อมี GPU ทั้งสองใช้สัญญาอนุญาต Apache และอ่านได้ 201 ภาษา โมเดลแบบโฮสต์จาก Anthropic, OpenAI, Google และรายอื่นก็ใช้ได้ [โมเดลที่แนะนำ](../../docs/llm.md#recommended-open-models)


## ใช้แทน SpamAssassin ได้หรือไม่

สำหรับการตั้งค่าส่วนใหญ่ ได้: โปรแกรมรองรับโปรโตคอลของ spamd ดังนั้น spamc, Exim และ Haraka ทำงานได้โดยไม่ต้องแก้ไข และเขียนส่วนหัว `X-Spam-*` แบบเดียวกัน แต่ไม่รันไฟล์กฎของ SpamAssassin [ทางเลือกแทน SpamAssassin](/spamassassin-alternative/)


## จะปฏิเสธอีเมลที่ถูกต้องหรือไม่

การปฏิเสธอีเมลปิดไว้โดยค่าเริ่มต้น: milter แค่ติดป้าย เมื่อใช้ `--reject` จะปฏิเสธเฉพาะข้อความที่ได้ 15 คะแนนขึ้นไป ด้วยข้อผิดพลาดชั่วคราว 451 ผู้ส่งจึงลองใหม่ และแก้ไขข้อผิดพลาดได้ด้วยการเปลี่ยนการตั้งค่า ตัวกรองเนื้อหาไม่ปฏิเสธอีเมลระหว่างเซสชัน SMTP เลย


## จะฝึกด้วยอีเมลของฉันได้อย่างไร

`spamscanner train --spam ~/Maildir/.Junk --ham ~/Maildir/cur --out model.json` แล้วใช้ `--model model.json` ไฟล์ mbox, Maildir, โฟลเดอร์ของไฟล์ `.eml` และชุดข้อมูล CSV หรือ JSON Lines ใช้ได้ทั้งหมด [การฝึกโมเดล](../../docs/training.md)


## ใช้งานโดยไม่มี Node.js ได้หรือไม่

ได้: ไบนารีแบบสแตนด์อโลนสำหรับ Linux, macOS และ Windows รวม Node.js และโมเดลไว้ในตัว `curl -fsSL https://github.com/spamscanner/spamscanner/releases/latest/download/install.sh | bash`


## ใครเป็นผู้สร้าง

[Forward Email](https://forwardemail.net) เพื่อใช้กับเซิร์ฟเวอร์อีเมลของตัวเอง
